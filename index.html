Approach

Both projects were designed end-to-end in Figma — from user flows and low-fidelity wireframes to fully polished, dark-mode-first UI kits. The focus throughout was consistency: shared type scales, spacing and component states across every screen so each app feels like a single, considered product rather than a set of disconnected pages.
